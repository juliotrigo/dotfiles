# Writing

## Technical text (asd-ste100)

Use the `asd-ste100` skill when you write or edit the text below. Do not wait for Julio to ask.

- Strict mode: text that agents read. Examples: AGENTS.md and CLAUDE.md files, skills, slash-command specs, prompts, tool descriptions, and error messages in code.
- STE-flavored mode: technical prose for people. Examples: PR descriptions, commit messages, Jira tickets, READMEs, docs, and replies to Julio in the conversation.

Do not use it for Slack messages or emails.

The skill's output format (the rewritten text only) applies when Julio asks for a rewrite. When you write your own text, apply the rules and keep the normal output.

When you edit an existing file, apply the rules only to the parts you change. Do not rewrite the rest without asking.

Where another rule is stricter, that rule wins. Examples: commit-message wrapping in `GIT.md` and the Jira section structure in `JIRA.md`.
